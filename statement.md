# Problem Statement

College messes prepare food for large groups, but demand changes from day to day. Over-preparation can create avoidable food waste, while informal observation makes it difficult to identify which foods, meals, or dates need attention. Mess administrators need a simple way to turn daily preparation and consumption records into useful evidence.

# Scope of the Project

This project accepts meal records containing a date, meal type, food item, prepared quantity, and consumed quantity. It calculates waste and waste percentage, groups records by food, meal, and day, classifies waste severity, detects unusually high waste, and produces rule-based recommendations.

The current version is a local command-line application using CSV storage. It does not include a web interface, database, machine learning, attendance integration, cost accounting, or automatic data collection from weighing equipment.

# Target Users

- College mess administrators
- Mess managers
- Hostel management
- Students involved in mess monitoring

# High-Level Features

- Meal data entry
- Waste calculation
- Food-wise analysis
- Meal-wise analysis
- Day-wise analysis
- Pattern detection
- Waste classification
- Recommendations
- Waste Intelligence Report
